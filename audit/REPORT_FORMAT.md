# Report format

Save the same content as `reports/YYYY-MM-DD.md`. Also write the spreadsheet and the dashboard (see CLAUDE.md). If email is sent, use:

Subject: "Owner Statement Audit — <Mon DD> — 🔴 <n> red / 🟡 <n> yellow" (or "✅ No red flags")

Body, in this order:
1. DATA STATUS (Rentvine rows checked; AppFolio coverage; any failures or checks not run)
2. Dollars at risk: total RED unpaid $ and RED already-paid $
3. 🔴 RED — FIX TODAY (unpaid first). Each item: Owner — Property, Unit / what is wrong / vendor, acct, ref, amount, date / what was checked / action / link
4. 🟡 YELLOW — PLEASE REVIEW
5. 💧 POSSIBLE LEAKS / UTILITY SPIKES (and resident-pays utilities billed to owners)
6. 🔁 OPEN ITEMS STILL OPEN (with days open from the first-seen date in audit/OPEN_ITEMS.md)
7. ✅ RESOLVED SINCE LAST REPORT (compare to the previous reports/baseline-*.json)
8. 📋 WATCH LIST CHANGES (new or changed non-8%/10% only)
9. Caught-and-voided count; known exceptions skipped count

Keep it to what a person must act on. Count both "lines" and "grouped items" and say which one a number is.
